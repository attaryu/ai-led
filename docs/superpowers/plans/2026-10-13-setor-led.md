# Setor ke LED Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah job `SETOR_LED` + endpoint `POST /dokumen/:id/setor-led` yang, per IKU, mencari Capaian dari LKPS/LED/bukti dukung lalu menghasilkan kategori Evaluasi dan narasi tabel LED (Analisis ketercapaian, Usulan target tahun depan, Strategi pencapaian, Sarpras; plus faktor/akar masalah/tindak lanjut bila belum memenuhi).

**Architecture:** Endpoint NestJS mengantre job BullMQ `SETOR_LED` (antrean `assessment-queue`); `worker.py::_handle_setor_led` memvalidasi prasyarat lalu memanggil modul baru `apps/ai/setor_led/`. Tiap IKU berjalan paralel (semaphore) dalam dua tahap: loop tool kecil mencari Capaian, lalu satu panggilan LLM JSON menentukan Evaluasi + narasi. Hasil dikembalikan sebagai return value job (`Job.result`), tanpa tabel baru. AMI tidak disentuh.

**Tech Stack:** NestJS 11 + Prisma 6 + class-validator + jest; Python 3.11 + LangChain (`langchain_core`, `langchain_ollama`/`langchain_openai`) + pgvector + pytest.

**Spec:** `docs/superpowers/specs/2026-10-13-setor-led-design.md`

## Global Constraints

- Endpoint: `POST /dokumen/:id/setor-led`, role `WRITE_ROLES` (`PENJAMIN_MUTU`, `PENYUSUN`), mengembalikan baris `Job` (`type: "SETOR_LED"`).
- Enum Evaluasi tepat tiga nilai: `MELAMPAUI`, `MEMENUHI`, `BELUM_MEMENUHI`.
- Kunci hasil per IKU: `kode`, `capaian{nilai,sumber}`, `evaluasi`, `analisisKetercapaian`, `usulanTargetTahunDepan`, `strategiPencapaian`, `sarprasDibutuhkan`, `tambahan{faktorPendukung,faktorPenghambat,akarMasalah,tindakLanjut}` (hanya `BELUM_MEMENUHI`), `error` (kegagalan per IKU; tanpa field lain).
- Status job: `completed` | `cancelled` | `error`; `cancelled` tetap mengembalikan IKU yang sudah selesai.
- Antrean: `assessment-queue`. `QUEUE_NAMES` di `worker.py` dan `queue-names.ts` tidak berubah.
- **File AMI tidak boleh diubah:** `agent/graph.py`, `agent/reasoning_graph.py`, `agent/state.py`, `agent/tools/*`, `api/routes/assessment.py`, `_handle_assessment_ami`, `triggerAssessment`, `trigger-assessment.dto.ts`.
- `search_evidence_documents` (tool AMI) tidak dipakai; gantinya `cari_bukti_dukung_prodi` (tanpa tag indikator).
- Model reasoning (`is_reasoning_model()`) ditolak; hanya model chat dengan tool calling asli.
- Capaian tidak ditemukan → IKU dikembalikan dengan `error`, **tanpa narasi**.
- Prompt memakai deskripsi gaya per bagian, **bukan** kutipan LED PENS (dokumen internal PENS).
- Commit: Conventional Commits bahasa Inggris, `type(scope): imperative lowercase subject`, tanpa titik di akhir (lihat `AGENTS.md`). Satu perubahan logis per commit.
- Tidak ada lint/format config untuk `apps/ai`; backend punya ESLint+Prettier (jangan jalankan `npm run lint` karena `--fix` menulis ke file lain).

## Review Focus

Masukan/kondisi yang tidak disebut spec tapi paling mungkin menggigit pengguna (tiap baris punya tes di task pemiliknya):

1. **Target berformat rentang/simbol** (`3,5 < MS ≤ 4,5`, `RIPK ≥ 3,25`) harus sampai ke prompt apa adanya, tanpa rusak oleh pemformatan — Task 5.
2. **Balasan model berbungkus `<think>…</think>` atau code fence ```json** harus tetap terbaca sebagai JSON — Task 6.
3. **Tool melempar exception di tengah loop** (mis. Postgres putus) tidak boleh menjatuhkan IKU itu atau job — Task 6.
4. **`kode`/`indikator`/`target` berisi spasi saja** harus ditolak di DTO (bukan lolos sebagai "tidak kosong") — Task 2.

import { ApiProperty, ApiPropertyOptional } from '@nestjs/swagger';
import { LedSourceMode } from '@ai-led/db';
import { Transform, Type } from 'class-transformer';
import {
  ArrayMinSize,
  IsArray,
  IsEnum,
  IsNotEmpty,
  IsOptional,
  IsString,
  ValidateNested,
} from 'class-validator';

/** Spasi di tepi dibuang sebelum validasi, supaya "   " dianggap kosong (IsNotEmpty saja meloloskannya). */
const trim = ({ value }: { value: unknown }) => (typeof value === 'string' ? value.trim() : value);

export class IkuInputDto {
  @ApiProperty({ example: 'IKU.REL.MHS.3' })
  @Transform(trim)
  @IsString()
  @IsNotEmpty()
  kode!: string;

  @ApiProperty({ example: 'Rata-rata minimal IPK lulusan dalam 3 tahun terakhir' })
  @Transform(trim)
  @IsString()
  @IsNotEmpty()
  indikator!: string;

  @ApiProperty({ example: 'PJJ: RIPK ≥ 3,25' })
  @Transform(trim)
  @IsString()
  @IsNotEmpty()
  target!: string;
}

export class TriggerSetorLedDto {
  @ApiProperty({
    type: [IkuInputDto],
    description: 'Daftar IKU yang diisi tabel analisisnya (minimal 1; `kode` unik dalam satu permintaan)',
  })
  @IsArray()
  @ArrayMinSize(1)
  @ValidateNested({ each: true })
  @Type(() => IkuInputDto)
  ikuList!: IkuInputDto[];

  // EDITOR: worker meng-index teks bab saat ini sebagai LED; UNGGAHAN: berkas LED yang diunggah. Sama seperti AMI.
  @ApiPropertyOptional({ enum: LedSourceMode })
  @IsOptional()
  @IsEnum(LedSourceMode)
  sumberLed?: LedSourceMode;

  @ApiPropertyOptional()
  @IsOptional()
  @IsString()
  lkpsBuktiDukungId?: string;

  // Harus salah satu dari apps/ai get_available_models(); divalidasi worker.
  @ApiPropertyOptional()
  @IsOptional()
  @IsString()
  model?: string;
}
```

   * "Setor ke LED": job terpisah dari AMI yang mengisi tabel analisis IKU (kategori Evaluasi + narasi).
   * Aturan LKPS sama dengan triggerAssessment (LKPS dokumen menang; kiriman klien hanya dipakai, dan jadi
   * LKPS dokumen, bila dokumen belum punya) -- ditulis ulang di sini, bukan di-refactor, supaya jalur AMI
   * tidak tersentuh.

"""Bentuk data proses "setor ke LED" (job SETOR_LED): input IKU, validasi keluaran LLM, dan
bentuk hasil per IKU yang dikembalikan sebagai return value job (Job.result).

Sengaja terpisah dari agent/ (AMI): Evaluasi di sini kategori tetap tiga nilai, bukan skor rubrik 0-4.
"""

from __future__ import annotations

from dataclasses import dataclass

EVALUASI: tuple[str, ...] = ("MELAMPAUI", "MEMENUHI", "BELUM_MEMENUHI")
BELUM_MEMENUHI = "BELUM_MEMENUHI"
NARASI_INTI: tuple[str, ...] = (
    "analisisKetercapaian",
    "usulanTargetTahunDepan",
    "strategiPencapaian",
    "sarprasDibutuhkan",
)
NARASI_TAMBAHAN: tuple[str, ...] = ("faktorPendukung", "faktorPenghambat", "akarMasalah", "tindakLanjut")


class SetorLedError(Exception):
    """Kegagalan satu IKU yang pesannya aman ditampilkan ke pengguna (masuk ke field `error`)."""


@dataclass(frozen=True)
class IkuInput:
    kode: str
    indikator: str
    target: str


def parse_iku_list(raw: object) -> list[IkuInput]:
    """Payload job -> daftar IKU. Backend sudah memvalidasi; ini pengaman terakhir karena worker
    mempercayai payload apa adanya. Raise ValueError (pesan Indonesia) bila tidak valid."""
    if not isinstance(raw, list) or not raw:
        raise ValueError("ikuList kosong -- kirim minimal satu IKU")

    hasil: list[IkuInput] = []
    terlihat: set[str] = set()
    for nomor, item in enumerate(raw, start=1):
        if not isinstance(item, dict):
            raise ValueError(f"IKU ke-{nomor} bukan objek")
        nilai = {k: str(item.get(k) or "").strip() for k in ("kode", "indikator", "target")}
        for kunci, isi in nilai.items():
            if not isi:
                raise ValueError(f"IKU ke-{nomor}: '{kunci}' wajib diisi")
        if nilai["kode"] in terlihat:
            raise ValueError(f"Kode IKU duplikat: {nilai['kode']}")
        terlihat.add(nilai["kode"])
        hasil.append(IkuInput(**nilai))
    return hasil


def _ambil_teks(sumber: dict, kunci: tuple[str, ...]) -> dict[str, str]:
    hasil: dict[str, str] = {}
    for k in kunci:
        isi = sumber.get(k)
        if not isinstance(isi, str) or not isi.strip():
            raise SetorLedError(f"Bagian '{k}' kosong dari model")
        hasil[k] = isi.strip()
    return hasil


def validasi_keluaran_llm(data: object) -> tuple[str, dict[str, str], dict[str, str] | None]:
    """JSON tahap 2 -> (evaluasi, narasi inti, tambahan atau None). Bagian tambahan wajib hanya bila
    BELUM_MEMENUHI dan diabaikan bila tidak. Raise SetorLedError bila tidak valid."""
    if not isinstance(data, dict):
        raise SetorLedError("Model tidak mengembalikan JSON yang bisa dibaca")

    evaluasi = data.get("evaluasi")
    if evaluasi not in EVALUASI:
        raise SetorLedError(f"Evaluasi di luar daftar yang diizinkan: {evaluasi!r}")

    inti = _ambil_teks(data, NARASI_INTI)
    tambahan = None
    if evaluasi == BELUM_MEMENUHI:
        sumber = data.get("tambahan")
        if not isinstance(sumber, dict):
            raise SetorLedError(
                "Bagian tambahan (faktor pendukung/penghambat, akar masalah, tindak lanjut) "
                "wajib untuk IKU yang belum memenuhi standar"
            )
        tambahan = _ambil_teks(sumber, NARASI_TAMBAHAN)
    return evaluasi, inti, tambahan


def hasil_sukses(
    kode: str, capaian: dict, evaluasi: str, inti: dict[str, str], tambahan: dict[str, str] | None
) -> dict:
    hasil = {
        "kode": kode,
        "capaian": {"nilai": capaian["nilai"], "sumber": capaian["sumber"]},
        "evaluasi": evaluasi,
        **inti,
    }
    if tambahan:
        hasil["tambahan"] = tambahan
    return hasil


def hasil_gagal(kode: str, pesan: str) -> dict:
    return {"kode": kode, "error": pesan}
```

"""Pembuat model chat untuk setor ke LED. Meniru agent/graph.py::_build_llm (provider switch, timeout,
num_predict, keep_alive, retry) tetapi: model dipilih per-permintaan, daftar tool bisa diberikan atau
tidak (tahap 2 tanpa tool), dan tidak mengubah apa pun di agent/ (AMI)."""

from __future__ import annotations

import os

from llm.chat_model import _is_thinking_model
from llm.ollama_client import create_ollama_client_from_env


def build_setor_llm(
    model: str | None,
    *,
    tools: list | None = None,
    temperature: float = 0.1,
    num_predict: int = 4096,
):
    client = create_ollama_client_from_env(model=model)
    provider = os.environ.get("LLM_PROVIDER", "ollama").lower()

    if provider == "openrouter":
        from langchain_openai import ChatOpenAI

        llm = ChatOpenAI(
            base_url="https://openrouter.ai/api/v1",
            api_key=os.environ["OPENROUTER_API_KEY"],
            model=client.model,
            temperature=temperature,
            max_tokens=num_predict,
        )
    else:
        from langchain_ollama import ChatOllama

        kwargs: dict = {
            "base_url": client.base_url,
            "model": client.model,
            "temperature": temperature,
            "num_predict": num_predict,
            # Tanpa timeout, koneksi macet ke Ollama jauh membuat IKU menggantung selamanya (lihat _build_llm).
            "client_kwargs": {"timeout": client.timeout_seconds},
            "keep_alive": client.keep_alive,
        }
        if client.api_key and not client.api_key.startswith("<"):
            kwargs["client_kwargs"]["headers"] = {"Authorization": f"Bearer {client.api_key}"}
        # Tahap tanpa tool menuntut JSON bersih: matikan thinking terpisah milik qwen3/nemotron.
        if tools is None and _is_thinking_model(client.model):
            kwargs["reasoning"] = False
        llm = ChatOllama(**kwargs)

    if tools:
        llm = llm.bind_tools(tools)
    return llm.with_retry(stop_after_attempt=3)
```

"""Pipeline per-IKU untuk job SETOR_LED. Tiap IKU berdiri sendiri (tanpa state bersama) dan dijalankan
paralel, dibatasi semaphore -- pola yang sama dengan api/routes/assessment.py::_run_assessment_pipeline.

Tahap 1 (cari_capaian): loop tool kecil mencari Capaian di LKPS / LED / bukti dukung prodi.
Tahap 2 (tulis_evaluasi_narasi): satu panggilan LLM JSON -> kategori Evaluasi + narasi.
"""

from __future__ import annotations

import asyncio
import contextvars
import json
import logging
from typing import Awaitable, Callable, Optional

from langchain_core.messages import HumanMessage, SystemMessage, ToolMessage

from agent.context import AssessmentContext, current_assessment_context
from agent.tools.led_tool import search_led_evidence
from agent.tools.lkps_tool import _registries, get_lkps_table
from llm.chat_model import no_think
from setor_led.llm import build_setor_llm
from setor_led.prompts import SYSTEM_CAPAIAN, bangun_prompt_capaian, bangun_prompt_evaluasi
from setor_led.schema import (
    IkuInput,
    SetorLedError,
    hasil_gagal,
    hasil_sukses,
    validasi_keluaran_llm,
)
from setor_led.tools import cari_bukti_dukung_prodi

logger = logging.getLogger(__name__)

MAX_TOOL_STEPS = 6          # panggilan tool maksimum per IKU sebelum model dipaksa menjawab
MAX_BAHAN_CHARS = 6000      # batas bahan tool yang diteruskan ke tahap 2
CANCEL_POLL_SECONDS: float = 3  # cek flag batal tiap ini detik, walau belum ada IKU yang selesai

TOOLS = [get_lkps_table, search_led_evidence, cari_bukti_dukung_prodi]
TOOLS_BY_NAME = {t.name: t for t in TOOLS}


def _extract_json(teks: str):
    # Import malas: agent.reasoning_graph berat dan hanya parser ini yang dibutuhkan.
    from agent.reasoning_graph import _extract_json as ekstrak

    return ekstrak(teks)


def daftar_tabel_lkps(tenant_id: str, dokumen_id: str) -> list[str]:
    """Nama sheet LKPS yang termuat untuk dokumen ini, untuk diberikan ke model di awal supaya tidak
    menebak tabel. Memakai cache internal lkps_tool karena tidak ada getter publik dan kode tool AMI
    sengaja tidak diubah. [] bila registry belum dimuat."""
    registry = _registries.get((tenant_id, dokumen_id))
    return list(registry.sheets.keys()) if registry is not None else []


def parse_capaian(content: object) -> dict | None:
    """Jawaban akhir tahap 1 -> {"nilai", "sumber"}, atau None bila tidak ditemukan/tidak terbaca."""
    data = _extract_json(content if isinstance(content, str) else str(content or ""))
    if not isinstance(data, dict) or not data.get("ditemukan"):
        return None
    nilai = str(data.get("nilai") or "").strip()
    if not nilai:
        return None
    return {"nilai": nilai, "sumber": str(data.get("sumber") or "").strip() or "tidak disebutkan"}


def _jalankan_tool(call: dict) -> str:
    """Satu panggilan tool dari model. Galat tool dikembalikan sebagai teks hasil tool (bukan raise),
    supaya satu tool yang gagal tidak menjatuhkan IKU -- model bisa mencoba tool lain."""
    tool = TOOLS_BY_NAME.get(call.get("name"))
    if tool is None:
        return json.dumps({"error": f"tool '{call.get('name')}' tidak tersedia"}, ensure_ascii=False)
    try:
        return str(tool.invoke(call.get("args") or {}))
    except Exception as exc:  # noqa: BLE001 -- sengaja luas, lihat docstring
        logger.warning("Tool %s gagal: %s", call.get("name"), exc)
        return json.dumps({"error": f"{type(exc).__name__}: tool gagal dijalankan"}, ensure_ascii=False)


def cari_capaian(llm, iku: IkuInput, tabel_lkps: list[str]) -> tuple[dict | None, str]:
    """Tahap 1. Mengembalikan (capaian atau None, bahan) -- bahan = gabungan hasil tool untuk tahap 2."""
    pesan = [SystemMessage(content=SYSTEM_CAPAIAN), HumanMessage(content=bangun_prompt_capaian(iku, tabel_lkps))]
    bahan: list[str] = []

    def _bahan() -> str:
        return "\n\n".join(bahan)[:MAX_BAHAN_CHARS]

    for _ in range(MAX_TOOL_STEPS):
        jawaban = llm.invoke(pesan)
        pesan.append(jawaban)
        panggilan = getattr(jawaban, "tool_calls", None) or []
        if not panggilan:
            return parse_capaian(jawaban.content), _bahan()
        for call in panggilan:
            keluaran = _jalankan_tool(call)
            bahan.append(f"[{call.get('name')}] {keluaran}")
            pesan.append(ToolMessage(content=keluaran, tool_call_id=call.get("id"), name=call.get("name")))

    # Batas langkah habis: paksa jawaban akhir. Bila model masih meminta tool, parse_capaian -> None.
    pesan.append(HumanMessage(content="Batas pemanggilan tool tercapai. Berikan jawaban akhir JSON sekarang."))
    return parse_capaian(llm.invoke(pesan).content), _bahan()


def tulis_evaluasi_narasi(llm, iku: IkuInput, capaian: dict, bahan: str, model: str | None = None):
    """Tahap 2. Satu percobaan + satu ulang bila JSON/enum tidak valid; lalu SetorLedError."""
    prompt = no_think(bangun_prompt_evaluasi(iku, capaian, bahan), model)
    terakhir: SetorLedError | None = None
    for _ in range(2):
        jawaban = llm.invoke(prompt)
        try:
            return validasi_keluaran_llm(_extract_json(str(jawaban.content or "")))
        except SetorLedError as exc:
            terakhir = exc
            logger.warning("Keluaran tahap 2 untuk %s tidak valid: %s", iku.kode, exc)
    raise terakhir  # type: ignore[misc]  # loop selalu berjalan >= 1 kali


def _proses_iku_sync(iku: IkuInput, model: str | None, tabel_lkps: list[str]) -> dict:
    """Seluruh pekerjaan satu IKU (sinkron, jalan di thread executor karena tool & LLM sinkron)."""
    llm_tool = build_setor_llm(model, tools=TOOLS)
    capaian, bahan = cari_capaian(llm_tool, iku, tabel_lkps)
    if capaian is None:
        raise SetorLedError("Capaian tidak ditemukan di LKPS/LED/bukti dukung")

    llm_narasi = build_setor_llm(model, temperature=0.2, num_predict=3000)
    evaluasi, inti, tambahan = tulis_evaluasi_narasi(llm_narasi, iku, capaian, bahan, model)
    return hasil_sukses(iku.kode, capaian, evaluasi, inti, tambahan)


async def proses_iku(
    iku: IkuInput,
    semaphore: asyncio.Semaphore,
    *,
    tenant_id: str,
    dokumen_id: str,
    accreditation_set_id: str,
    study_program_id: Optional[str],
    model: Optional[str],
    tabel_lkps: list[str],
) -> dict:
    """Satu IKU, dibatasi semaphore. Tidak pernah raise (selain CancelledError): kegagalan menjadi
    hasil_gagal supaya IKU lain tetap jalan. Pesan galat tak terduga sengaja generik (tanpa teks mentah)."""
    async with semaphore:
        try:
            # run_in_executor tidak mewarisi contextvars: salin eksplisit agar tool melihat konteks ini.
            # indicator_no=0: IKU bukan indikator rubrik, dan tool yang dipakai tidak membacanya.
            current_assessment_context.set(
                AssessmentContext(tenant_id, dokumen_id, 0, accreditation_set_id, study_program_id)
            )
            ctx = contextvars.copy_context()
            return await asyncio.get_running_loop().run_in_executor(
                None, ctx.run, _proses_iku_sync, iku, model, tabel_lkps
            )
        except SetorLedError as exc:
            return hasil_gagal(iku.kode, str(exc))
        except Exception as exc:  # noqa: BLE001
            logger.exception("Gagal memproses IKU %s", iku.kode)
            return hasil_gagal(iku.kode, f"Gagal diproses ({type(exc).__name__}) -- lihat log server untuk detail.")


async def jalankan_setor_led(
    iku_list: list[IkuInput],
    *,
    max_parallel: int,
    tenant_id: str,
    dokumen_id: str,
    accreditation_set_id: str,
    study_program_id: Optional[str],
    model: Optional[str],
    on_progress: Optional[Callable[[int, int], Awaitable[None]]] = None,
    is_cancelled: Optional[Callable[[], Awaitable[bool]]] = None,
) -> tuple[list[dict], bool]:
    """Jalankan semua IKU paralel. Mengembalikan (hasil berurutan sesuai input untuk IKU yang selesai,
    dibatalkan). `is_cancelled` dipoll tiap CANCEL_POLL_SECONDS meski belum ada IKU yang selesai (endpoint
    LLM yang macet bisa membuat tak satu pun selesai berminit-menit); bila true, tugas yang belum selesai
    dibatalkan dan yang sudah selesai tetap dikembalikan."""
    tabel_lkps = daftar_tabel_lkps(tenant_id, dokumen_id)
    semaphore = asyncio.Semaphore(max_parallel)
    tugas = {
        asyncio.ensure_future(
            proses_iku(
                iku,
                semaphore,
                tenant_id=tenant_id,
                dokumen_id=dokumen_id,
                accreditation_set_id=accreditation_set_id,
                study_program_id=study_program_id,
                model=model,
                tabel_lkps=tabel_lkps,
            )
        ): iku.kode
        for iku in iku_list
    }

    hasil_per_kode: dict[str, dict] = {}
    pending = set(tugas)
    selesai = 0
    dibatalkan = False
    while pending:
        done, pending = await asyncio.wait(pending, timeout=CANCEL_POLL_SECONDS, return_when=asyncio.FIRST_COMPLETED)
        for t in done:
            hasil_per_kode[tugas[t]] = t.result()
            selesai += 1
            if on_progress is not None:
                await on_progress(selesai, len(iku_list))
        if is_cancelled is not None and await is_cancelled():
            dibatalkan = True
            break

    if dibatalkan:
        for t in pending:
            t.cancel()
        await asyncio.gather(*pending, return_exceptions=True)
        logger.info("Setor LED dibatalkan (%d/%d IKU selesai)", selesai, len(iku_list))

    return [hasil_per_kode[i.kode] for i in iku_list if i.kode in hasil_per_kode], dibatalkan
```

```python
async def _handle_setor_led(job) -> dict:
    """"Setor ke LED": mengisi tabel analisis IKU (kategori Evaluasi + narasi) untuk satu Dokumen LED.
    Terpisah dari _handle_assessment_ami -- tidak memakai rubrik/skor 0-4 dan tidak menulis
    AssessmentSession; hasilnya dikembalikan sebagai return value job (-> Job.result). Worker ini hanya
    pemicu: prasyarat (LED terindeks, LKPS termuat, model valid) dicek di sini, logika per-IKU ada di
    setor_led/pipeline.py.

    Prasyarat sama dengan AMI (LED + LKPS wajib; tanpa salah satunya job berhenti dengan error, bukan
    menulis dari konteks kosong). Model reasoning ditolak: setor ke LED memakai tool calling asli dan
    tidak menduplikasi protokol JSON-tool agent/reasoning_graph.py.
    """
    from agent.graph import is_reasoning_model
    from agent.tools.lkps_tool import load_lkps_for_document
    from db.postgres_client import get_document_accreditation_set
    from llm.ollama_client import get_available_models
    from setor_led.pipeline import jalankan_setor_led
    from setor_led.schema import parse_iku_list

    payload = job.data
    dokumen_id = payload["dokumenId"]
    tenant_id = payload["tenantId"]
    study_program_id = payload.get("programStudiId")

    try:
        iku_list = parse_iku_list(payload.get("ikuList"))
    except ValueError as e:
        return {"status": "error", "error": str(e)}

    available = get_available_models()
    model = payload.get("model") or available[0]
    if model not in available:
        return {"status": "error", "error": f"Unknown model: {model}. Available: {available}"}
    if is_reasoning_model(model):
        return {
            "status": "error",
            "error": f"Model reasoning ({model}) belum didukung untuk setor ke LED -- pilih model chat dengan tool calling.",
        }

    accreditation_set_id = get_document_accreditation_set(dokumen_id)
    if accreditation_set_id is None:
        return {
            "status": "error",
            "error": "Dokumen ini belum memilih Set Akreditasi — pilih Set Akreditasi dulu sebelum setor ke LED.",
        }

    led_error = await _prepare_led_index(tenant_id, dokumen_id, payload.get("sumberLed", "EDITOR"))
    if led_error:
        return {"status": "error", "error": led_error}

    try:
        lkps_loaded = load_lkps_for_document(
            tenant_id, dokumen_id,
            payload.get("lkpsBuktiDukungId") or _document_lkps_evidence_id(tenant_id, dokumen_id),
        )
    except Exception as e:
        logger.exception("Gagal memuat LKPS untuk tenant=%s dokumen=%s", tenant_id, dokumen_id)
        return {"status": "error", "error": f"Gagal membaca LKPS: {_err_msg(e)}"}
    if not lkps_loaded:
        return {"status": "error", "error": "LKPS belum dipilih untuk setor ke LED -- pilih atau unggah Data LKPS dulu."}

    async def _report_progress(completed: int, total: int) -> None:
        try:
            await job.updateProgress({"completed": completed, "total": total})
        except Exception:
            logger.exception("Gagal mengirim progress job %s", job.id)

    # Tombol Batalkan (JobsService.cancel di apps/backend) menitip flag lewat Redis dengan key job.id --
    # NestJS tidak bisa menjangkau loop async di proses worker ini langsung. Sama dengan ASSESSMENT_AMI.
    import redis.asyncio as aioredis

    redis_client = aioredis.from_url(os.environ.get("REDIS_URL", "redis://localhost:6379"))

    async def _is_cancelled() -> bool:
        try:
            return bool(await redis_client.get(f"job:cancel:{job.id}"))
        except Exception:
            logger.exception("Gagal cek status batal job %s, lanjut seperti biasa", job.id)
            return False

    try:
        hasil, dibatalkan = await jalankan_setor_led(
            iku_list,
            max_parallel=int(os.environ.get("ASSESSMENT_MAX_PARALLEL", "5")),
            tenant_id=tenant_id,
            dokumen_id=dokumen_id,
            accreditation_set_id=accreditation_set_id,
            study_program_id=study_program_id,
            model=model,
            on_progress=_report_progress,
            is_cancelled=_is_cancelled,
        )
    finally:
        await redis_client.aclose()

    return {"status": "cancelled" if dibatalkan else "completed", "hasil": hasil}
```
