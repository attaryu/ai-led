# Paper Artifacts

Ready-to-paste materials for the open-weight LLM benchmark paper on
Indonesian higher education accreditation.

## Files

| File | Purpose |
|---|---|
| `01_abstract_outline.md` | Title, abstract (~220 words), 7-section IMRaD outline (~6 pages) |
| `02_figures.md` | 5 figures: architecture diagram + 4 plottable matplotlib recipes with data |
| `03_tables.md` | 6 tables in both Markdown and LaTeX; ready to drop into Overleaf |

## Generation pipeline

All numbers traceable to:
- `data/benchmark_results.csv` — 180 (model, indicator) pairs
- `data/reference_scores_claude.csv` — 60 reference scores
- `data/benchmark_report.md` — auto-generated by `scripts/analyze_benchmark.py`

To regenerate stats after adding more data:
```bash
docker compose exec backend python -m scripts.analyze_benchmark
```

## Anonymization checklist before submission

- [ ] Remove `[link]` strings pointing to internal PENS systems
- [ ] Strip absolute file paths from logs/listings

  for institution-identifying phrases

## Suggested venues (in submission order)

1. **arXiv** — preprint immediately, gives DOI for citing
2. **ICITISEE / SENTIKA / SNATIA / SENATIK** — Indonesian conference
   proceedings, IEEE Xplore indexed, fast review (≤4 weeks)
3. **JISKa / JTIIK / JNTETI** — Sinta 2-3 Indonesian journal,
   1-3 month review
4. **IEEE Access (Q1)** — submit AFTER expanding to 2-3 programs and
   adding human-expert validation subset
